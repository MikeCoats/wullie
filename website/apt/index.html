Wullie's apt repository

On Debian 12 or later, or Ubuntu 22.04 or later, add Wullie's apt repository and apt will install Wullie and keep it up to date along with the rest of your system. There are packages for amd64 and arm64.

Adding the repository

Add the repository with the following script:

curl -fsSL https://wullie.mikecoats.xyz/apt/setup.sh | sudo sh
What the script does

It downloads the key that signs the repository, and tells apt where the repository is and which key it's signed with. You can run the same steps yourself instead.

@SETUP_SH@

With the repository added, you can install Wullie with a normal sudo apt update && sudo apt install wullie. The package also installs the man page and completions for bash, zsh and fish. Wullie can then be kept up to date with a regular sudo apt upgrade.

Checking the key

The key's fingerprint is:

A9A9D45A44CF7703C29361C6EAB8603C2404B883

To check the one you downloaded matches:

gpg --show-keys /etc/apt/keyrings/wullie.asc

Removing the repository

sudo apt remove wullie
sudo rm /etc/apt/sources.list.d/wullie.sources /etc/apt/keyrings/wullie.asc
