Installing Wullie

Wullie is a single program with no runtime dependencies. On Debian and Ubuntu, use the Debian package. Anywhere else, use Cargo if you have it, or a prebuilt tarball if you don't.

The commands below are for Wullie @VERSION@, the latest release. Every release is on GitHub.

Debian and Ubuntu

There are packages for amd64 and arm64, which install on Debian 12 or later and Ubuntu 22.04 or later. Download the one for your machine, and install it with apt: 

curl -LO https://github.com/MikeCoats/wullie/releases/download/v@VERSION@/wullie_@VERSION@_amd64.deb
sudo apt install ./wullie_@VERSION@_amd64.deb

On arm64, use wullie_@VERSION@_arm64.deb instead. The package also installs the man page and completions for bash, zsh and fish.

With Cargo

cargo-binstall downloads the prebuilt binary for your platform: 

cargo binstall wullie

Or build it from source, which needs Rust 1.100 or later: 

cargo install wullie

Either way, Wullie is installed in ~/.cargo/bin, without the man page or completions. They're in the tarballs below.

Prebuilt tarballs

Platform Download
Linux on x86-64 x86_64-unknown-linux-gnu
Linux on x86-64, statically linked x86_64-unknown-linux-musl
Linux on ARM64 aarch64-unknown-linux-gnu
macOS on Apple Silicon aarch64-apple-darwin
macOS on Intel x86_64-apple-darwin
Windows on x86-64 x86_64-pc-windows-msvc

The Linux gnu builds need glibc 2.34 or later. The musl build has no such requirement, and runs on any x86-64 Linux, including Alpine.

Each tarball has the wullie binary (wullie.exe on Windows), the wullie.1 man page, shell completions, the README and the licence. To install the binary for just yourself on Linux or macOS: 

tar xzf wullie-@VERSION@-x86_64-unknown-linux-gnu.tar.gz
mkdir -p ~/.local/bin
install -m 755 wullie-@VERSION@-x86_64-unknown-linux-gnu/wullie ~/.local/bin/

Make sure ~/.local/bin is on your PATH. Most Linux distributions add it for you, but macOS doesn't.

On Windows 10 and later, tar is built in, so the same tar xzf command works in PowerShell. Put wullie.exe in a folder on your PATH.

Checking a download

Every download has a matching .sha256 file alongside it on the release. Download both into the same folder, then check one against the other: 

sha256sum --check wullie-@VERSION@-x86_64-unknown-linux-gnu.tar.gz.sha256

On macOS, use shasum -a 256 --check instead. On Windows, compare the output of Get-FileHash wullie-@VERSION@-x86_64-pc-windows-msvc.tar.gz with the hash in the .sha256 file.

Shell completions and the man page

The Debian package installs these for you. From a tarball, copy the ones you want from its completions folder:

Shell File Copy it to
bash wullie.bash ~/.local/share/bash-completion/completions/wullie
zsh _wullie any folder in your $fpath
fish wullie.fish ~/.config/fish/completions/wullie.fish
Elvish wullie.elv anywhere, then eval it from rc.elv
PowerShell _wullie.ps1 anywhere, then dot-source it from your $PROFILE

To install the man page for just yourself:

mkdir -p ~/.local/share/man/man1
install -m 644 wullie-@VERSION@-x86_64-unknown-linux-gnu/wullie.1 ~/.local/share/man/man1/

Upgrading

Wullie doesn't update itself. To upgrade, install the new release the same way you installed the old one: download and apt install the new Debian package, run cargo binstall wullie or cargo install wullie again, or replace the binary with the one from a new tarball.

wullie --version shows which version you have.
